# 🌐 Meus Sites
Este repositório reúne sites que desenvolvi ao longo dos meus estudos e projetos, tanto individuais quanto acadêmicos.

Atualmente, o repositório conta com ow seguintes projetos:

- 🔹 Site Feteps: Hydrignis
  - Site desenvolvido para a 16ª edição da FETEPS, com foco em apresentar a proposta do projeto Hydrignis de forma clara e visual.
 
- 🟡 Exercício JavaScript: Treinando com o JavaScript
  - Site desenvolvido para aprender e treinar com o JavaScript. Contendo: Verificar de maior de idade, Calculador de média de notas, verificar de maior número entre um conjunto e verificador de número primo

- 🔴 Site da Etec: Site para Etec de Taboão da Serra
   - Site desenvolvido para a Etec de Taboão da Serra, com foco em divulgar e valorizar a instituição.
 
- 📋 Exercício de lista: Usando listas em HTML e CSS
  - Site desenvolvido para aprender a como usar listas em HTML e CSS.
 
- 📄 Formulário de cadastro: Formulário para cadastro simples
    - Site desenvolvido com o intuito de aprender a fazer formulário em HTML e CSS.

- 🛠 Formulário de manutenção: Formulário para manutenção de sistema interno
  - Site desenvolvido com foco em diversificar o conhecimento sobre formulários em HTML e CSS
 
- 🚗 Tabela para mecânicos: Tabela de preços de serviços para mecânicos
    - Site desenvolvido com o intuito de aprender a fazer tabelas em HTML e CSS.
 
- 🦘 Canguru: Site informativo sobre a Canguru de 2026
    - Site desenvolvido com o objetivo de apresentar informações sobre a Canguru de 2026 de forma clara e organizada.

- ⚖️ Calculadora de IMC
    - Site desenvolvido para calcular o Índice de Massa Corporal (IMC) com base nos dados inseridos pelo usuário.
